Danh mục

Kéo thả để đổi thứ tự. Kéo một món thả vào danh mục để chuyển món. Formules cũng là một danh mục: thêm, sửa như món bình thường (giá có thể để trống).

    Món

      Chọn một món để sửa.

      Liên kết trên đầu trang và chân trang

      Dán đường dẫn đầy đủ, bắt đầu bằng https://. Để trống thì nút tự ẩn.

      Biểu tượng: đặt tệp biểu tượng chính thức vào assets/icons/instagram.svg và assets/icons/facebook.svg (định dạng SVG). Khi chưa có tệp, trang web hiện chữ « Instagram », « Facebook ».

      Đẩy lên GitHub

      Trang web thật (GitHub Pages) lấy tệp từ kho GitHub. Sau khi « Lưu thay đổi », bấm « Kiểm tra thay đổi » để xem tệp nào khác với GitHub, rồi « Đẩy lên GitHub ». Khoảng 1–2 phút sau trang web cập nhật. Không có tệp nào trên GitHub bị xoá.

      Còn thay đổi chưa lưu. Bấm « Lưu thay đổi » trước khi đẩy.

      Kết nối

      Đang kiểm tra…

      Cách tạo token (làm một lần)
      1. Đăng nhập GitHub bằng tài khoản sở hữu kho, mở Settings → Developer settings → Personal access tokens → Fine-grained tokens (đường tắt: github.com/settings/personal-access-tokens/new).
      2. Token name: xiu-site admin. Expiration: tuỳ chọn (ví dụ 1 năm; hết hạn thì tạo lại).
      3. Repository access: Only select repositories → chọn xiu-site.
      4. Permissions → Repository permissions → Contents: Read and write (Metadata: Read-only tự bật). Không cần quyền nào khác.
      5. Bấm Generate token, chép chuỗi bắt đầu bằng github_pat_, dán vào ô Token ở trên, bấm « Lưu và kiểm tra ».

      Token được lưu trong tệp ~/.xiu-site-admin.json của người dùng Windows, ngoài thư mục xiu-site. Không gửi token cho ai. Nếu lộ token: vào lại trang trên, bấm Revoke.
